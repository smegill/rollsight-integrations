# RollSight

通过原生 Owlbear 扩展请求实体骰子，并分享公开的 RollSight 结果卡片。

在 Owlbear 共享弹窗中查看公开结果，在 RollSight 中展开默认折叠的回放，并通过符合条件的套餐分享会话 RollStats。

通过实体骰子完成受支持的 Forge 角色卡动作，并可选择将结果摘要分享到 Rumble 聊天中。

一台 Windows 或 Mac 电脑、兼容的相机和掷骰表面即可。可以先用网络摄像头或支持的手机方案。请选择适合电脑的安装程序；无需购买特殊骰子或 RollSight 硬件。

使用免费应用识别自己的骰子并连接您的游戏桌。无需银行卡。

[下载 RollSight](https://www.rollsight.com/download) · [比较游戏集成](https://www.rollsight.com/integrations)

## 快速上手

1. 请房间所有者使用下方扩展清单添加并启用 RollSight。
2. 从房间内 RollSight 的“连接”选项卡获取代码。在桌面应用的“连接骰子 → Owlbear Rodeo”中输入。
3. 在房间的 RollSight 面板中选择骰子，然后点击“请求骰子”。
4. 掷骰，在 RollSight 中检查朝上的点数并发送。在 Owlbear 中查看总数，在“结果”中查看回放。

仅支持公开掷骰。Forge 通过自身控件应用伤害或治疗。不提供通用角色卡或自动资源支持。更正不会重复游戏效果。回放和 RollStats 需要符合条件的套餐以及上传或同步。
