# RollSight 实体骰子

在 Foundry 中打开 RollSight 设置并复制你的玩家代码。在游戏设置 → 核心 → 骰子中，将默认方式设为 RollSight 实体骰子并保存。检查各类骰子的单独设置。在 Foundry 中发起掷骰，等待 RollSight 提示出现后再掷实体骰子。

## 关联此世界（GM）

GM 必须先关联此世界，您才能刷新玩家代码。

将此个人代码复制到桌面应用。在 Foundry 骰子配置中选择 RollSight 或手动，然后在 Foundry 中发起掷骰。

在 Foundry 中发起掷骰，然后从桌面应用发送实体骰子。不支持远程桌面掷骰请求。

## 为手动掷骰接收骰子

同时填入原生手动提示。Foundry 保留原有控件并计算修正值。

新的掷骰请求会自动接收骰子。如果同时打开多个提示，最新的提示优先接收；关闭后，先前的提示会恢复接收。

## 接收 RollSight 骰子

关闭以退出此会话。待处理的掷骰仍可在 Foundry 中手动完成。

## 使用浏览器扩展

通过 RollSight 扩展接收本地桌面结果。此模式下禁用云接收。

此浏览器无法协调标签页。每位 RollSight 玩家请只使用一个 Foundry 标签页。

## 没有待处理掷骰时发布骰子

使用当前聊天可见性发布普通实体骰子。先在 Foundry 中发起先攻、攻击和优势掷骰。

## RollSight 回放

打开回放；选择图像以查看原始大小。

## 刷新连接

RollSight 无法连接。请检查世界关联并在模块设置中刷新玩家代码。

另一个标签页正在为此玩家接收 RollSight 骰子。请关闭它，然后刷新此连接。

骰子未被接受。请发送各骰子范围内的整数值。

RollSight 无法应用此次发送。再次发送前请检查待处理掷骰。

## 按战斗回合自动切换 OBS 场景

使用 RollSight Foundry 模块 1.1.91 或更新版本，并在同一世界中启用 OBS Utils。这些控制与回放叠加层相互独立。

在 OBS 中，使用 GM 提供的服务器地址创建 Foundry 浏览器来源：/game 用于游戏视图，/stream 用于 Stream 用户。请在 /stream 来源中登录稍后将选为 OBS 操作员的用户。

对每个 Foundry 浏览器来源，打开属性并将页面权限设为高级访问或完全访问。/game 和 /stream 的权限分别设置。更改后刷新各来源。仅用于回放的链接不需要场景控制权限。

切换场景时保持 /stream 控制器加载。关闭“不可见时关闭来源”，并在各场景中复用同一来源。使用此浏览器来源连接时，无需启用 OBS Utils WebSocket 或 API 访问。

以 GM 身份打开游戏设置 → RollSight → 配置 OBS 回合场景。选择 Stream 用户作为 OBS 操作员，然后刷新 OBS 场景。从下拉列表选择每个角色及其 OBS 场景。也可为未映射 NPC 的回合和战斗结束选择场景。

保存 OBS 场景，启用按战斗回合切换 OBS 场景，并取消勾选暂停自动切换。未映射玩家的回合会保留当前场景。

映射、操作员及启用和暂停设置会保存在此 Foundry 世界中。Stream 可在服务器启动后再连接。连接后会检查当前战斗回合。需要自动切换时，来源必须保持连接。

直播前推进测试战斗的回合并检查场景，然后测试暂停和恢复。如果没有场景，请检查 /stream 的权限，刷新其浏览器缓存，再刷新场景列表。重命名 OBS 场景后，请选择新名称并重新保存。
